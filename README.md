## 🧩 Design System

사내 서비스 전반의 UI 기반이 되는 컴포넌트 라이브러리 2종을 **초기 설계부터 npm 배포·운영까지 단독으로** 담당하고 있습니다.

- **[<ins>@cadian/ui</ins>](https://dev-design.cadian.com)** — 공용 컴포넌트 50여 종, v2.0 개편 후 30회 이상 릴리즈<br>
  CSS Variables 디자인 토큰 · 다크모드 기본 제공, 컴포넌트 단위 분할 빌드(트리셰이킹), GitLab CI 배포 파이프라인<br>
  CADian Drive 전면 마이그레이션을 직접 수행하고, Help Center v2 등 타 팀 신규 서비스의 UI 기반으로 채택
- **[<ins>@cadian/ui-admin</ins>](https://dev-admin-design.cadian.com)** — 어드민 전용 컴포넌트 45종 · 문서 페이지 54종<br>
  Radix Primitives를 내장하되 산출물에는 자체 네이밍(`cd_a-`)만 노출되도록 치환하는 아키텍처 설계<br>
  소비 서비스 요청·이슈 14건을 당일~익일 릴리즈로 대응 (RichTextEditor CMS 확장, Sortable 교차 컨테이너 드래그 등)
- **릴리즈 자동화** — Jira · GitLab · Slack을 MCP로 연동한 Claude Code 워크플로우로<br>
  이슈 생성 → 커밋 → 머지 → npm 게시 → 배포 검증 → 릴리즈 노트 공유까지 파이프라인화
